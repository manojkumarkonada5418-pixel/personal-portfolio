# Manoj Kumar — Portfolio

A responsive personal portfolio for performance marketing and AI automation, built with HTML, CSS and vanilla JavaScript.

## Features

- Full-length portrait with a cursor-driven particle dissolve and reconstruction effect
- Layered industry cards with corner-opening transitions, keyboard controls and swipe navigation
- Marketing funnel and interactive AI workflow
- WhatsApp and telephone contact links
- Responsive layouts and reduced-motion support

## Run locally

Serve the `dist` directory with a static HTTP server. For example, with Node.js installed:

```sh
npx serve dist
```

Open the local address printed by the server. No build step is required.

## Files

- `dist/index.html`: page content and metadata
- `dist/style.css`: shared styles
- `dist/hero.css`: full-length portrait hero
- `dist/industries.css`: industry showcase
- `dist/app.js`: interactions and animations
- `dist/portrait-full.png`: portrait asset

## Hosting

Deploy `dist` to a static hosting provider. Update the canonical and Open Graph URLs in `index.html` to match the final live domain. The current metadata contains the previously reserved Site address; it does not indicate an active deployment.
